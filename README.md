# Portfolio

Static recreation of the Figma portfolio long-page (`作品集web长图`), with typography scale, whitespace, and scroll-motion rhythm inspired by [studiomodular.be](https://studiomodular.be/).

## Run

```bash
cd ~/portfolio
python3 -m http.server 8765
```

Open http://localhost:8765

## Stack

- Semantic HTML
- Custom CSS (fluid type, responsive grid)
- GSAP + ScrollTrigger (CDN)
